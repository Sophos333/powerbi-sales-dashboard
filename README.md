## ⚙️ Built With

- **Power BI Desktop**
- **DAX** (Data Analysis Expressions)
- **Custom Measures** & Interactive Slicers
- **PBIX File** (Uploaded above)

---

## 🚀 How to Use

1. Download the `.pbix` file from this repo.
2. Open it in [Power BI Desktop](https://powerbi.microsoft.com/desktop/).
3. Explore the visuals, filters, and KPIs.

---

## 🧠 Purpose

To visualize sales performance by **segment, category, and time**, and demonstrate advanced **Power BI** skills like:

- Custom KPIs
- Drill-down visuals
- Performance tracking
